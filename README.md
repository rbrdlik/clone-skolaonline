## 🎯 Cíl projektu  
Cílem je vyvinout funkční replikaci systému **Škola Online**, která zahrnuje:
- Webovou aplikaci pro učitele  
- Mobilní aplikaci pro studenty  
- Vlastní backend a datastore  
- Vlastní autentizaci  

---

## 🛠️ Technologie
### **Frontend**
- ⚛️ React – webová aplikace (učitelé)  
- 📱 React Native – mobilní aplikace (studenti)
### **Backend**
- 🟩 Node.js + Express – REST API  
- 🍃 MongoDB – NoSQL databáze

---

## 🔐 Funkcionality
### **Autentizace**
- Vlastní implementace přihlašování  
- Bez použití externích providerů

---

## 🧑‍🏫 Webová aplikace (učitel)
### ✔️ Správa tříd a žáků
- Přidávání / úprava / mazání žáků  
- Tvorba a editace tříd  
### ✔️ Správa známek
- Přidávání známek  
- Úprava existujících  
- Přehled po třídách a jednotlivcích  
### ✔️ Správa rozvrhu
- Vytváření rozvrhů pro jednotlivé třídy  
- Týdenní přehledy + detailní náhledy

## 📱 Mobilní aplikace (student)
### 📌 Zobrazení známek
- Aktuální výsledky  
- Průměry a historie
### 📌 Zobrazení třídy
- Informace o vlastní třídě  
- Spolužáci
### 📌 Zobrazení rozvrhu
- Denní / týdenní rozvrh  
- Nadcházející hodiny
